# web-starter

> 开箱即用的 Web 项目脚手架 · Opinionated web project starter

## 特性 / Features

- TypeScript 全链路，严格模式 / end-to-end TypeScript with strict mode
- 约定式路由与 API 目录 / convention-based routes and API folder
- 内置 ESLint + Prettier + Vitest / lint, format and test out of the box
- 一键部署（Docker / 静态导出）/ one-command deploy

## 快速开始 / Quick start

```bash
npm create web-starter@latest my-app
cd my-app
npm install
npm run dev
```

## 目录 / Layout

```
src/routes/    页面路由 / page routes
src/api/       接口处理 / API handlers
src/components/ 组件 / components
src/lib/       工具函数 / utilities
```
